# VitalCore Hospital Website

Official public website and press/creator resources for VitalCore Hospital.

Public pages:

- Main game website: `index.html`
- Press and creator kit: `press-kit.html`
- Search-engine discovery: `robots.txt` and `sitemap.xml`

Official public website for VitalCore Hospital. The site includes verified development information, authentic in-game Cedar Grove captures, an embedded gameplay reel, and links to the official Discord, itch.io page, and TikTok account.

Gameplay images and video are exported captures only. No raw Unity, Epic, Fab, or Asset Store source files are distributed through this repository.
