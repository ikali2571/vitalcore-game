# VitalCore website update

This ZIP contains replacement website files for the GitHub Pages repository.

## Upload
1. Open the `ikali2571/vitalcore-game` repository.
2. Replace `index.html`, `styles.css`, and `script.js` with these versions.
3. Keep the existing branded images in the repository root:
   - `vitalcore-logo.png`
   - `vitalcore-icon.png`
   - `vitalcore-hero.jpg`
   - `vitalcore-key-art.jpg`
4. Commit to the branch used by GitHub Pages.

## Before publishing
- Replace the placeholder Discord button link in `index.html` (`id="discord-link"`) with the real invite URL.
- Add real gameplay screenshots when ready.
- Review feature wording before announcing Early Access.

The update is responsive and contains no external libraries.
